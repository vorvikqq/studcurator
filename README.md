# Студкуратор — інструмент оцінювання кандидатів

Локальний веб-застосунок для перегляду анкет кандидатів у студкуратори (з Google Forms)
та паралельного виставлення оцінок кількома рецензентами.

## Встановлення

```
pip install -r requirements.txt
```

## Запуск

```
streamlit run app.py
```

## Куди покласти дані

Покладіть експортований із Google Forms файл `candidates.csv` у цю ж теку (поруч із
`app.py`) — застосунок автоматично його знайде на сторінці **Import**. Також можна
завантажити файл вручну через file uploader на цій сторінці. Кодування має бути UTF-8;
роздільник (кома чи крапка з комою) визначається автоматично.

## Як працює оцінювання та усереднення

Кожен кандидат отримує стабільний `candidate_id`, обчислений із нормалізованих ПІБ та
Telegram — це дозволяє повторно імпортувати CSV (наприклад, після нових відповідей у
формі) без втрати вже виставлених оцінок і без дублювання кандидатів.

Кожен рецензент оцінює кандидата за 6 критеріями (1–5 балів) і залишає загальний
коментар. Один рецензент може оцінити одного кандидата лише один раз — повторне
збереження оновлює його попередню оцінку, а не створює нову. Різні рецензенти
оцінюють кандидата незалежно один від одного (на сторінці кандидата видно чужі оцінки,
але це не впливає на форму власного оцінювання). Середній бал кандидата — це середнє
арифметичне по всіх виставлених оцінках усіх рецензентів, окремо по кожному критерію
та загалом; результати з менш ніж кількома оцінками позначаються на сторінці
**Results**, щоб було видно, кому ще бракує покриття.

Дані зберігаються в SQLite-файлі `curator_app.db` (створюється автоматично при
першому запуску) у режимі WAL, що дозволяє кільком браузерним сесіям одночасно
читати й писати без блокувань.

## (Опційно) Деплой на Streamlit Community Cloud

Щоб інші рецензенти могли заходити за посиланням, а не запускати застосунок локально:
1. Заведіть цей проєкт (без `curator_app.db`, він створиться сам) у репозиторій на
   GitHub.
2. На [share.streamlit.io](https://share.streamlit.io) підключіть репозиторій і
   вкажіть `app.py` як головний файл.
3. Завантажте `candidates.csv` через сторінку **Import** уже в розгорнутому
   застосунку (або закомітьте його в репозиторій, якщо це прийнятно з точки зору
   приватності даних).

Майте на увазі: безкоштовний тариф Streamlit Cloud використовує ефемерне сховище —
SQLite-файл може скидатися при перезапуску контейнера. Для довготривалого спільного
використання варто розглянути зовнішню БД (наприклад, Turso/LibSQL або Postgres) або
регулярно вивантажувати результати через сторінку **Results**.
