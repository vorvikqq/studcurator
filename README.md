# Студкуратор — інструмент оцінювання кандидатів

Локальний веб-застосунок для перегляду анкет кандидатів у студкуратори (з Google Forms)
та паралельного виставлення оцінок кількома рецензентами.

## Встановлення

```
pip install -r requirements.txt
```

## Запуск

```
streamlit run app.py
```

## Акаунти та вхід

Доступ до застосунку — лише через логін/пароль, акаунти не самореєструються.

- **Перший запуск:** акаунтів ще немає, тож застосунок сам запропонує створити
  перший акаунт **адміністратора** прямо на екрані входу.
- **Далі:** новi акаунти (рецензентів чи інших адмінів) створює лише
  адміністратор — на сторінці **Admin** (логін, ім'я, пароль, роль). Видати
  готові логін/пароль кожному рецензенту — ваша справа.
- **Ролі:**
  - **Рецензент** — бачить кандидатів, ставить власні оцінки, бачить лише
    свій особистий прогрес. Не бачить оцінок, коментарів чи середніх балів
    інших рецензентів — жодних чужих оцінок ніде в інтерфейсі.
  - **Адміністратор** — бачить усе: агреговані результати всіх рецензентів
    (сторінка **Results**), прогрес по кожному рецензенту (Дашборд),
    імпорт CSV (сторінка **Import**) і керування акаунтами (**Admin**).
    Сторінки Import, Results і Admin доступні лише адміністратору.

Паролі зберігаються у БД як PBKDF2-хеш із індивідуальною сіллю (не у
відкритому вигляді).

## Куди покласти дані

Покладіть експортований із Google Forms файл `candidates.csv` у цю ж теку (поруч із
`app.py`) — застосунок автоматично його знайде на сторінці **Import**. Також можна
завантажити файл вручну через file uploader на цій сторінці. Кодування має бути UTF-8;
роздільник (кома чи крапка з комою) визначається автоматично.

## Як працює оцінювання та усереднення

Кожен кандидат отримує стабільний `candidate_id`, обчислений із нормалізованих ПІБ та
Telegram — це дозволяє повторно імпортувати CSV (наприклад, після нових відповідей у
формі) без втрати вже виставлених оцінок і без дублювання кандидатів.

Кожен рецензент оцінює кандидата за 4 числовими критеріями (1–5 балів: досвід в ОСС,
відповіді у формі, презентація на співбесіді, відповіді на кейси), відмічає прапорцем
досвід студкураторства (так/ні) та вписує місцезнаходження текстом — і залишає
загальний коментар. Один рецензент може оцінити одного кандидата лише один раз —
повторне збереження оновлює його попередню оцінку, а не створює нову.

Рецензенти оцінюють кандидатів **незалежно й наосліп**: ніхто, крім адміністратора,
не бачить чужих оцінок, коментарів чи середніх балів — лише власний прогрес. Середній
бал кандидата — це середнє арифметичне по 4 числових критеріях усіх рецензентів
(досвід студкураторства та місцезнаходження в середній бал не входять — вони лише
показуються окремо, щоб було видно, чи є в кандидата такий досвід). Ці агреговані
результати бачить тільки адміністратор на сторінці **Results**, де також позначені
кандидати з менш ніж кількома оцінками, щоб було видно, кому ще бракує покриття.

Дані зберігаються в SQLite-файлі `curator_app.db` (створюється автоматично при
першому запуску) у режимі WAL, що дозволяє кільком браузерним сесіям одночасно
читати й писати без блокувань.

## (Опційно) Деплой на Streamlit Community Cloud

Щоб інші рецензенти могли заходити за посиланням, а не запускати застосунок локально:
1. Заведіть цей проєкт (без `curator_app.db`, він створиться сам) у репозиторій на
   GitHub.
2. На [share.streamlit.io](https://share.streamlit.io) підключіть репозиторій і
   вкажіть `app.py` як головний файл.
3. Завантажте `candidates.csv` через сторінку **Import** уже в розгорнутому
   застосунку (або закомітьте його в репозиторій, якщо це прийнятно з точки зору
   приватності даних).

Майте на увазі: безкоштовний тариф Streamlit Cloud використовує ефемерне сховище —
SQLite-файл може скидатися при перезапуску контейнера. Для довготривалого спільного
використання варто розглянути зовнішню БД (наприклад, Turso/LibSQL або Postgres) або
регулярно вивантажувати результати через сторінку **Results**.
